# 绿芽 blooming

面向小学阶段儿童的健康教育网页原型，以“小芽”伙伴和花园成长为线索，将饮食记录、运动记录、健康小知识和家庭陪伴串联起来。

当前版本采用约 1.6 英寸儿童手表的界面形式，通过左右滑动或点击底部定位圆点切换页面。项目早期方案名为“画伴·食光”，此仓库说明以现有的“绿芽 blooming”手表端代码为准。

## 快速开始

无需安装依赖或执行构建，直接用浏览器打开 [`web-demo/index.html`](./web-demo/index.html) 即可体验主要流程。

若要体验浏览器语音识别，建议通过本地 HTTP 服务访问。在项目根目录执行：

```sh
python3 -m http.server 8000 --directory web-demo --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:8000>。语音功能取决于浏览器支持、系统语音和麦克风权限；可先在支持 Web Speech API 的桌面浏览器中体验。

## 页面与功能

| 页面 | 当前可体验的内容 |
| --- | --- |
| 花园 | 小芽伙伴、花园场景、随记录变化的花园成长进度 |
| 饮食打卡 | 拍照、语音、卡片三种方式入口；六类食物卡片选择；即时文字和语音反馈 |
| 运动打卡 | 跑步、骑车、行走、游泳、爬山、跳绳六种选择；开始、计时、结束和反馈 |
| 知识花房 | 彩虹餐盘小知识、选择题、“小芽问一问”预设问答和浏览器语音提问 |
| 陪伴小屋 | 示例家长鼓励、语音播报、饭后散步、挑水果和彩虹盘家庭任务选择 |

点击“开始”进入原型，左右滑动手表屏幕切换页面，也可以点击底部五个定位圆点。桌面端右侧显示当前页面的设计说明。

推荐先体验以下流程：

1. 进入饮食页，选择“卡片记录”，选一种食物并完成记录，查看小芽反馈，再返回花园。
2. 进入运动页，选择一种运动，开始计时后结束记录，查看反馈和花园变化。
3. 进入知识花房，完成选择题，打开“小芽问一问”，选择预设问题或尝试语音提问。
4. 进入陪伴小屋，播放家长鼓励并切换家庭任务。

## 当前实现范围

- **界面与状态：** 原生 HTML、CSS、JavaScript 实现，无前端框架、后端服务或数据库。记录和成长进度保存在页面内存中，刷新后恢复初始状态。
- **饮食记录：** 卡片选择可交互；拍照和饮食语音入口目前用于演示完成流程，尚未接入相机采集、餐盘识别或饮食语音转写。
- **运动记录：** 使用浏览器计时器记录本次时间，尚未接入手表传感器、步数、定位或运动平台。
- **小芽问答：** 语音提问调用浏览器的 `SpeechRecognition` / `webkitSpeechRecognition`，回答由本地关键词规则和预设文案生成，尚未接入大模型服务。不支持语音识别的浏览器仍可使用预设问题。
- **语音播报：** 使用浏览器 `speechSynthesis`，声音由设备系统提供；识别服务可能需要联网，具体取决于浏览器。
- **家长分享：** 分享开关、家长鼓励和家庭任务为前端演示，尚未建立家长账号、绑定关系或真实消息发送。
- **视觉素材：** 伙伴、标识和图标位于本地 `assets/` 目录；Google Fonts 字体需要联网，无法加载时使用系统字体。

花园进度用于演示成长反馈，不代表健康分、营养评估或身体评价。

## 本地修改与检查

- 修改页面结构或应用名称：编辑 `web-demo/index.html`。
- 修改配色、手表尺寸、字体或动效：编辑 `web-demo/styles.css`。
- 修改食物分类、运动项目、反馈、问答或任务：编辑 `web-demo/app.js` 中对应的数据和函数。
- 替换伙伴和图标：更新 `web-demo/assets/`，并同步对应文件名引用。

若已安装 Node.js，可执行 JavaScript 语法检查：

```sh
node --check web-demo/app.js
```

修改后重新打开或刷新页面，按上面的体验步骤检查交互。

## 静态部署

此项目可以托管在支持静态文件的网站服务中。将发布目录设为 `web-demo`，无需安装依赖或配置构建命令；保留 `assets/`、CSS 和 JavaScript 的相对路径。

当前使用 GitHub Pages，从 `main` 分支的 `/ (root)` 目录发布。网页入口位于 `web-demo/`，因此在线演示地址包含 `/web-demo/`。更新 `main` 分支后，GitHub Pages 会重新构建和发布网站。
